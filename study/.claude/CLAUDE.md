# Study Notes Guidelines

## Critical Rule: Never Overwrite Note Files

- **NEVER overwrite** any `.md` note or work files (e.g., `day*-work.md`, `*-design.md`) unless explicitly instructed to overwrite specific sections.
- Always **APPEND** new content to existing note files.
- When updating, use the `Edit` tool to modify specific sections rather than `Write` which replaces the entire file.
- If asked to "add" or "record" results, this means APPEND — not replace.
